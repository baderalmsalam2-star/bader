# تطبيق رحلة المدينة النبوية ١١ — ١٤٤٨هـ/٢٠٢٦م

تطبيق ويب لإدارة رحلة المدينة النبوية: المشاركون، الغرف، اللجان، الحضور،
الصلوات، لوحات الشرف، والمالية — مع لوحة إدارة كاملة وأكواد QR للدخول.

بُني بـ **Node.js + [Hono](https://hono.dev)** وقاعدة بيانات **SQLite** المدمجة
في Node (`node:sqlite`).

---

## المتطلبات

- **Node.js نسخة 22.5 أو أحدث** (لأن التطبيق يستخدم `node:sqlite` المدمجة).

## التشغيل

```bash
npm install
npm start
```

ثم افتح المتصفح على: <http://localhost:3000>

> على ويندوز، يمكن التشغيل بالضغط المزدوج على **`تشغيل التطبيق.bat`**،
> والإيقاف عبر **`إيقاف التطبيق.bat`**. سكربت `start.ps1` يشغّل الخادم
> ويفتح رابطاً عاماً عبر Cloudflare Tunnel (يتطلب `cloudflared.exe`).

## أوامر إضافية

| الأمر | الوظيفة |
|------|---------|
| `npm start` | تشغيل الخادم (`src/server.js`) |
| `npm run seed` | تهيئة قاعدة البيانات من `data/seed.json` |
| `npm test` | كل الاختبارات — تعمل على قاعدة معزولة ولا تمسّ `data/` |

> يمكن تحويل مجلد البيانات بمتغيّر البيئة `RIHLA_DATA` (تستعمله الاختبارات).

## 💰 قاعدتان في المالية

**دفتران لا يختلطان:** كل مصروف يُقيَّد على دفتر **المدينة** أو دفتر **مكة**،
والتقرير يُقرأ لكل دفتر وحده أو للاثنين معاً. الدفتر الافتراضي عند التسجيل هو
المدينة الحالية (إعداد `current_city`).

**اليوم المالي من الفجر إلى الفجر:** ما سُجّل بعد منتصف الليل وقبل الفجر يُقيَّد
على يوم أمس — كما يحسبها الوفد فعلاً. وإذا دخل فجر الغد أُقفل اليوم **نهائياً**:
تُحفَظ لقطة إجماليه في `money_day_close` فلا يُضاف إليه ولا يُحذف منه شيء، ولا
يُفتح بعدها بأي صلاحية. الإقفال حكم زمني يجري تلقائياً بلا مؤقّت في الخلفية.

وقت الفجر يُؤخذ من أوقات الصلاة المجلوبة لكل مدينة، وعند تعذّر الجلب يُستعمل
وقت احتياطي يُضبط من صفحة المصروفات (`fajr_fallback`، افتراضه ٤:٣٠) — فالإقفال
لا يصحّ أن يتعطّل لانقطاع الإنترنت.

## 📣 قفل «تفاعلت» في الإعلامية

الرابط لا يُعطى للمشارك مباشرة، بل يمرّ بمسار تحويل (`/media/:id/go`) يسجّل الفتح
ثم يحوّله للرابط. وزر «تفاعلت» يُردّ عمّن لم يُسجَّل له فتح — ولو أرسل الطلب بيده،
لأن الشرط يُفحص على الخادم لا في المتصفح. وبهذا يكون رقم التفاعل الذي تراه
الإعلامية رقماً صادقاً لا رقماً مُدَّعى.

الروابط تُقبل بـ `http`/`https` فقط، فلا يصل `javascript:` ولا `file:` إلى جهاز
مشارك. والتفاعل يُحتسب مرة واحدة، ونقاطه تُمنح مرة واحدة.

## ⚠️ ملاحظة عن البيانات

مجلد `data/` (قاعدة البيانات `rihla.db`، النسخ الاحتياطية، `secret.key`،
وملف `seed.json`) **غير مرفوع** إلى هذا المستودع عمداً، لأنه يحتوي على
**بيانات شخصية** (أسماء، أرقام مدنية، أرقام جوالات) لا يصحّ نشرها.
يُنشئ التطبيق قاعدة بيانات جديدة تلقائياً عند أول تشغيل. للاسترجاع الكامل
بالبيانات، استخدم نسختك المحفوظة من مجلد `data/`.
